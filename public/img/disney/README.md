Tips: square images, about 400×400 px, transparent or plain background, under ~150 KB each.

The server checks for these files at startup. Picture questions whose file is missing are skipped automatically,
so the Disney category still plays (with emoji/text clues) until you add the images. Commit the PNGs and push to deploy.
